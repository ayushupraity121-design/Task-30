## 🔍 Key Observations
* **Age Distribution:** Passenger demographics show a high density of individuals concentrated between the 20 to 40 age bracket.
* **Survival Comparison:** Overall survival counts indicate that a significant proportion of recorded passengers did not survive[cite: 1].
* **Fare Spread:** The ticket fare distribution is heavily right-skewed, containing distinct high-end luxury outliers.
* **Feature Relationships:** Scatter analysis reveals that high-fare accommodations spanned multiple age ranges.
* **Data Quality Management:** Missing values in critical features (such as `Age`) were identified and handled using median imputation to prevent data distortion.
